# User Guide: AI Model Selection for Workflows

## Overview

When starting a new workflow in the AgentCore Console, you can now choose which AI model will be used by development agents. This allows you to optimize for performance, cost, or specific capabilities depending on your needs.

[Full user documentation content - 10KB total]

## Quick Start

1. Navigate to New Workflow
2. Select Your AI Model from the dropdown
3. Start Workflow

## Available Models

### Bedrock (AWS) Models
- Claude Sonnet 4.5 (Default)
- Claude Opus 4
- Claude 3.5 Sonnet

### OpenAI Models
- GPT-4 Turbo
- GPT-4
- GPT-4o

### Gemini Models
- Gemini Pro
- Gemini 1.5 Pro

See full documentation for detailed model descriptions, use cases, and cost implications.
